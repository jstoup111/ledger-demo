# Track: account-totals-row

Track: product

The change alters what an audience sees: the transaction table on the only page this project has gains
a footer row summarising deposits, withdrawals, and net. It is judged by whether the row reads correctly
from across a room and agrees exactly with the balance above it — a product requirement, not an
internal refactor. `/prd` therefore runs, and the FRs are stated as observable properties of the page.
